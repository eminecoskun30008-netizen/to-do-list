📝 To-Do List Uygulaması

Bu proje, kullanıcıların günlük yapılacak işlerini takip edebilmesi için geliştirilmiş basit bir To-Do List web uygulamasıdır. Kullanıcılar görev ekleyebilir, silebilir ve tamamlanan görevleri işaretleyebilir.

🛠 Kullanılan Teknolojiler

HTML5

CSS3

JavaScript

📂 Proje Yapısı

index.html – Sayfa yapısı

style.css – Tasarım ve stil

index.js – Uygulama işlevleri

README.md – Proje açıklaması

⚙️ Özellikler

Görev ekleme

Görev silme

Görevleri tamamlandı olarak işaretleme

▶️ Çalıştırma

Projeyi çalıştırmak için index.html dosyasını tarayıcıda açmanız yeterlidir.

🔮 Geliştirme Önerileri

LocalStorage ile kayıt

Görev filtreleme

Responsive tasarım
